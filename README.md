## 🇨🇳 简体中文

U校园AI自动刷时长工具

### 主要功能

- ✅ **自动遍历目录** - 智能识别Unit、Section、Micro各级目录并自动切换
- ✅ **自动点击Tab/Task** - 支持多层级Tab与Task全自动点击
- ✅ **时长智能分配** - 计划等待时间依次均分到勾选的目录、Tab 和 Task
- ⏱️ **倒计时显示** - 每个页面显示本步倒计时，进度一目了然
- ⏸️ **暂停、继续与停止** - 暂停后可修改目录、Tab、Task 和时长；继续时从首个勾选目录重新执行新计划
- 🔄 **提示弹窗处理** - 仅关闭已知的信息提示，不自动点击通用确认或提交按钮
- 📝 **操作日志显示** - 全过程实时日志，出错可查
- 📱 **悬浮球启动** - 美观浮动球入口，UI简洁现代

### 安装使用

#### 1. 安装浏览器扩展
首先需要安装用户脚本管理器（任选其一）：
- [Tampermonkey](https://www.tampermonkey.net/) (推荐)
- [Violentmonkey](https://violentmonkey.github.io/)
- [Greasemonkey](https://www.greasespot.net/)

#### 2. 安装脚本
点击下方链接安装脚本：
- [从 GitHub 安装](https://github.com/whaaoo/UnipusAIAutoPlayer/raw/main/unipus_ai_auto_player.user.js)


#### 3. 使用步骤
1. 打开U校园课程学习平台页面 (https://ucontent.unipus.cn/*)
2. 点击页面右下角的绿色悬浮球 🎓
3. 在控制面板中勾选目标目录，设置计划等待时长（分钟）；Tab/Task 留空表示全部，可填 `1,3` 或 `1-3`
4. 点击「🚀 开始刷课」按钮
5. 点击「⏸️ 暂停」后可调整配置；点击「▶️ 继续」应用修改，或点击「⏹️ 停止」结束本次计划
6. 日志区域会实时显示所有步骤和进度

### 适用范围

- ✅ U校园平台 (ucontent.unipus.cn)
- ✅ 新视野大学英语系列课程
- ✅ 适配多种三级目录结构；具体课程仍取决于页面 DOM 是否匹配

## 🇺🇸 English

UCampus AI Auto Duration Assistant Tool

### Features

- ✅ **Auto Directory Traversal** - Automatically recognizes and switches between Unit, Section, Micro directories
- ✅ **Auto Tab/Task Click** - Supports multi-level Tab and Task automatic clicking
- ✅ **Smart Duration Allocation** - Divides planned waiting time among selected directories, tabs and tasks
- ⏱️ **Countdown Display** - Shows countdown for each page, progress at a glance
- ⏸️ **Pause, Resume and Stop** - Edit selections or duration while paused; resuming with changes restarts a complete new plan
- 🔄 **Informational Notices** - Dismisses only known notices; generic confirmation and submission buttons are left to the user
- 📝 **Operation Log Display** - Real-time logs throughout the process, easy to troubleshoot
- 📱 **Floating Ball Launcher** - Beautiful floating ball entrance with clean and modern UI

### Installation

#### 1. Install Browser Extension
First, install a userscript manager (choose one):
- [Tampermonkey](https://www.tampermonkey.net/) (Recommended)
- [Violentmonkey](https://violentmonkey.github.io/)
- [Greasemonkey](https://www.greasespot.net/)

#### 2. Install Script
Click the link below to install:
- [Install from GitHub](https://github.com/whaaoo/UnipusAIAutoPlayer/raw/main/unipus_ai_auto_player.user.js)


#### 3. Usage
1. Open UCampus course learning platform page (https://ucontent.unipus.cn/*)
2. Click the green floating ball 🎓 in the bottom right corner
3. Select target directories and waiting time (minutes). Leave Tab/Task blank for all, or enter `1,3` or `1-3`
4. Click "🚀 Start Learning" button
5. Pause to edit the configuration, resume to apply it, or use Stop to end the plan
6. Log area will display all steps and progress in real-time

### Compatibility

- ✅ UCampus Platform (ucontent.unipus.cn)
- ✅ New Horizon College English Series
- ✅ Multiple three-level directory layouts; actual compatibility depends on the page DOM

## v5.2.14 使用说明与支持范围

- **配置生效方式**：运行中的目录、Tab、Task 和时长修改，在暂停后点击继续时一起校验。配置改变后，从第一个勾选目录重新开始，重新分配完整的新时长；不会扣除之前已经运行的时间。只改 Tab/Task 也会生效。无效输入会保持暂停。
- **序号格式**：从 1 开始，支持 `1,3`、`1-3` 和中文逗号；留空选全部。拒绝小数、倒序区间、无限值和非法字符。Tab/Task 序号超出实际列表且没有任何匹配时，停止并提示。
- **视频模式**：默认关闭。开启后视频播放不计入页面等待时间；纯视频页面播放结束后可进入下一页。暂停会暂停受脚本控制的视频；关闭视频模式或停止计划会结束视频控制。视频播放失败、连续 60 秒无进度或累计等待 30 分钟会报错停止，不会被标记为播放完成。需要时以静音方式尝试自动播放，结束控制后恢复原来的静音设置。
- **计时含义**：填写的是本地计划等待时间，页面加载、视频播放等会影响实际总耗时；纯视频页面可能不消耗其分配的等待时间。脚本不读取服务端学习时长，结束后需在平台核对学习记录。
- **iframe 范围**：跨域通信支持目录扫描及点击，并校验父子窗口、域名和请求编号。跨域 iframe 内的 Tab、Task 和视频控制尚未完整支持；此版本不保证所有课程页面可用。同源 iframe 中的目录与视频可尝试直接访问。
- **弹窗与反馈**：只自动关闭明确识别的信息提示，其他弹窗需手动处理。反馈下载为 JSON 诊断计数，不包含页面正文、账号、课程标题或链接参数。
- **安装分支版本**：本优化分支的测试安装入口为 [fix/runtime-stability 脚本](https://github.com/whaaoo/UnipusAIAutoPlayer/raw/refs/heads/fix/runtime-stability/unipus_ai_auto_player.user.js)。请替换已安装的旧版，避免两个副本同时运行。脚本自动更新地址仍指向 `main`。

### 繁體中文補充

修改設定後繼續會重新執行完整的新計畫，先前時間不會扣除。影片時間不計入页面等待；純影片頁面結束後可直接跳轉。跨域 iframe 目前支援目錄掃描及點選，尚未完整支援其中的 Tab、Task 和影片。學習記錄以平台顯示為準。

### English notes

Resuming with changed settings starts a full new plan from the first selected directory. Earlier elapsed time is not deducted. Video playback is excluded from page waiting time, and video-only pages can advance when playback ends. Stalled or failed videos stop the plan with an error. Cross-origin iframe support currently covers menu discovery and clicking, not full tab/task/video control. Local completion does not confirm server-recorded learning time. Feedback exports diagnostic counts instead of page HTML.

## 开发与验证

安装使用仍然只需要一个 `.user.js` 文件，无构建步骤和运行依赖。

开发检查需要 Node.js 20 或更新版本，无需安装 npm 依赖：

```sh
npm test
```

测试使用 Node.js 内置测试运行器、隔离的脚本上下文、可控计时器及轻量 DOM 测试夹具，覆盖配置重启、暂停/停止、视频生命周期、输入校验、消息来源、请求回包、界面恢复和任务执行。它们不替代真实课程页面的浏览器验证。

手动验证建议：选择单个目录运行；暂停后只修改 Tab/Task；在最后一个目录修改时长并继续；播放视频时暂停和关闭视频模式；停止后再次启动；刷新目录后确认勾选和序号保留。对未适配的跨域课程请保留错误日志并按需提供脱敏结构。
